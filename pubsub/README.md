# Pub/Sub

Before running `init.py` make sure you are authenticated with `gcloud` CLI by running `gcloud auth list`. If you do not see your `Credentialed Accounts`, just run `gcloud auth login` to authenticate.

The `init.py` script creates the different resources required to communicate with the Pub/Sub emulator, such as `topics` and `subscriptions`.

When you run Okuna in an IDE, make sure these environment variables are set correctly:

```
GOOGLE_CLOUD_PROJECT_ID=holi-dev
PUBSUB_EMULATOR_HOST=localhost:8085
```

The first entry is a fixed value.
The second entry is generated by calling `gcloud beta emulators pubsub env-init` and uses the same port where we start the emulator.
